# -Kh-m-ph-qu-o-tia-n-c-b-ng-GeoGebra-Ai-c-th-i-qua-ph-a-d-i-m-kh-ng-b-t-
Tình huống thực tiễn mô phỏng quỹ đạo tia nước dạng parabol tại công viên. Học sinh sử dụng GeoGebra để xây dựng hàm số bậc hai, tạo thanh trượt thay đổi chiều cao và vị trí người, từ đó khám phá khoảng vị trí có thể đứng dưới tia nước mà không bị chạm vào dòng nước.
